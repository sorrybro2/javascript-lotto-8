# javascript-lotto-precourse
## 기능 요구사항

[x] 로또 번호는 1~45사이의 중복되지 않은 숫자 6개로 구성한다.
[x] 구입 금액을 입력받아 1,000원 단위로 나눈 개수만큼 로또를 발행한다.
[x] 발행된 각 로또의 번호는 오름차순 정렬하여 출력한다.
[] 사용자가 구매한 로또와 당첨 번호를 비교하여 **등수별 당첨 개수**를 계산한다.
    - 1등: 6개 번호 일치 / 2,000,000,000원
    - 2등: 5개 번호 + 보너스 번호 일치 / 30,000,000원
    - 3등: 5개 번호 일치 / 1,500,000원
    - 4등: 4개 번호 일치 / 50,000원
    - 5등: 3개 번호 일치 / 5,000원
[] 당첨 통계를 출력하고, 총 수익률도 출력한다. 단, 수익률은 소수점 둘째 자리에서 반올림하여 출력한다.
    ```
    3개 일치 (5,000원) - 1개
    4개 일치 (50,000원) - 0개
    5개 일치 (1,500,000원) - 0개
    5개 일치, 보너스 볼 일치 (30,000,000원) - 0개
    6개 일치 (2,000,000,000원) - 0개
    총 수익률은 62.5%입니다.
    ```
[] 사용자가 잘못된 값을 입력한 경우 `[ERROR]`로 시작하는 에러 메세지를 출력하고, 해당 입력부터 다시 받는다.

## 입출력 요구사항

- 해당 입출력 조건이 안맞을 시, 모든 예외 메시지는 [ERROR]로 시작하며, 뒤에 해당 예외 메시지의 내용을 포함한다.

- 모든 번호들은 정수이어야 한다.

### 구입 금액 입력
[x] 구입 금액은 자연수이어야 한다.
[x] 구입 금액이 로또 가격(1,000원)으로 나누어 떨어져야 한다.
[x] 구입 금액은 로또 가격인 1,000원 이상이어야 한다.

### 당첨 번호 입출력
[x] 당첨 번호는 배열이어야 한다.
[x] 당첨 번호에 중복이 있으면 안된다.
[x] 당첨 번호가 6개이어야 한다.
[x] 당첨 번호/보너스 번호는 1~45 안에 있어야 한다. 

### 보너스 번호 입출력
[x] 보너스 번호를 한 개다.
[x] 보너스 번호는 당첨 번호와 중복될 수 없다.
