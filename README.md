# javascript-lotto-precourse

## 기능 요구사항
- [x] 로또 번호는 1~45 사이의 중복되지 않은 숫자 6개로 구성한다.
- [x] 구입 금액을 입력받아 1,000원 단위로 나눈 개수만큼 로또를 발행한다.
- [x] 발행된 각 로또의 번호는 오름차순 정렬하여 출력한다.
- [x] 사용자가 구매한 로또와 당첨 번호를 비교하여 등수별 당첨 개수를 계산한다.
  - [x] 1등: 6개 번호 일치 / 2,000,000,000원
  - [x] 2등: 5개 번호 + 보너스 번호 일치 / 30,000,000원
  - [x] 3등: 5개 일치 / 1,500,000원
  - [x] 4등: 4개 일치 / 50,000원
  - [x] 5등: 3개 일치 / 5,000원
- [x] 당첨 통계를 출력하고, 총 수익률을 소수점 둘째 자리에서 반올림해(소수 첫째 자리까지) 출력한다.
- [x] 잘못된 입력은 `[ERROR]`로 시작하는 메시지를 출력하고 재입력한다.

## 입출력 요구사항
- [x] 모든 예외 메시지는 `[ERROR]` 로 시작한다.
- [x] 모든 번호는 정수여야 한다.

### 구입 금액 입력
- [x] 자연수(정수)여야 한다.
- [x] 로또 가격(1,000원)으로 나누어 떨어져야 한다.
- [x] 1,000원 이상이어야 한다.

### 당첨 번호 입력
- [x] 6개여야 한다.
- [x] 중복이 없어야 한다.
- [x] 1~45 범위여야 한다.

### 보너스 번호 입력
- [x] 한 개여야 한다.
- [x] 당첨 번호와 중복될 수 없다.
- [x] 1~45 범위여야 한다.
